Add a result

Review the evidence before you submit it.

A valid standard run with categorical measurement evidence can save identifier-minimized JSON or open the reviewed GitHub pull request for you. Choose the public option at the end of the run, inspect the complete record, and confirm it. You can still select a saved file here for a browser-only check. This page never accepts a raw report or sends the file anywhere.

The JSON omits direct machine and contributor identifiers, but it does include exact hardware, runtime, and any reported runtime-configuration details. Those details, especially alongside performance results, can make a setup recognizable. Your GitHub account and pull request will also be public.

Check a prepared submission

The fastest route is litb run --profile standard --submission pr --submission-model <report-model-id>. The model option may be omitted for a single-model run. To stop at a local file, choose --submission save, then select that JSON here.

JSON only, up to 256 KB. Your file stays in this browser.
